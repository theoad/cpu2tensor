# Add a native tensor event

The recipe is now a runnable [notebook tutorial](tutorials/normalization.ipynb).
It follows a three-field executable-layout event through native capture,
validation, owned tensor storage and a learning experiment using real relocated
executions. The recorded dataset lets contributors run the notebook without a VM;
it also shows how to collect new data.

See [the experiment evidence](normalization-results.md) for CPU/MPS results and
limits, and [the signal contract](instrumentation.md) for the wire format.
